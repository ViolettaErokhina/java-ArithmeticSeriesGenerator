# java-ArithmeticSeriesGenerator

код на языке JAVA для данной задачи: На ввод поступает три числа: начало ряда, шаг, количество шагов. Выведите на экран все числа полученного ряда. Пр. 1 2 5 → 1, 3, 5, 7, 9.

Запуск через командную строку командой: java ArithmeticSeriesGenerator

В поле "Введите начало ряда:" указываем 1.

В поле "Введите шаг:" указываем 2.

В поле "Введите количество шагов:" 5.

В ответе получим: 1, 3, 5, 7, 9 - что означает исправную работу кода согласно условию задачи.
